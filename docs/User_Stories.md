# User Stories

## Document Management
1. As a user, I want to **upload a document** (PDF, raw text etc.) to Alexandria so that it can be added to my personal knowledge base.
2. As a user, I want to **view a list of all my uploaded documents** so that I can easily browse my entire collection.
3. As a user, I want to **view an uploaded document** directly in Alexandria so that I can read the full text if the summary isn't enough.
4. As a user, I want to **delete an uploaded document** from my knowledge base so that I can remove outdated or irrelevant information.

## Summary and Entity Extraction

5. As a user, I want Alexandra to **automatically generate a summary** upon uploading a document so that I can understand its main points without reading the entire text.
6. As a user, I want to see the auto-generated **summary displayed alongside the document details** so that I can quickly recall the documents content.
7. As a user, I want Alexandria to **automatically identify and extract key entities (dates, names etc.) from my document** so that I don't have to manually pick them out.
8. As a user, I want Alexandria to **automatically assign tags based on the document's content** so that my knowledge base is categorized without requiring manual effort.
9. As a user, I want to **see the extracted entities and assigned tags for each document** so that I know exactly how it has been categorized.

## Search

10. As a user, I want to **search my knowledge base using keywords** so that I can find relevant documents containing specific terms.
11. As a user, I want to **see matched tags, keywords, and summaries highlighted in the search results** so that I can quickly identify why a document was returned.
12. As a user, I want to **filter my document list by tags** so that I can narrow down search results to a specific topic.
13. As a user, I want to **filter my documents by extracted entities** (e.g., a specific person or organization) so that I can find all documents referencing them.

## Question Answering (RAG)

14. As a user, I want to **ask natural-language questions about my uploaded documents** so that I can quickly find specific answers without manually searching through documents.
15. As a user, I want Alexandria's **generated answers to include references back to the source documents** so that I can verify the information and read the original context.
